# Android companion app (Phase 1C)

Kotlin + Camera2 + MediaCodec (no web wrapper). Two encoders from one camera:
low-latency preview (RTP/SRTP) and local high-quality recording in the
crash-safe segment format. Protocol and architecture:
[docs/PHONE_CAMERA_PROTOCOL.md](../../docs/PHONE_CAMERA_PROTOCOL.md) §13.
